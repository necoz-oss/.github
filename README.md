# .github

Community guidelines, contributing resources, and the organization profile for [Necoz](https://github.com/necoz-oss). 😸

This repository maintains:

- The [organization profile](profile/README.md)
- Shared community guidelines: [Contributing](CONTRIBUTING.md), [Code of Conduct](CODE_OF_CONDUCT.md), and [Security](SECURITY.md)
- Default [issue templates](.github/ISSUE_TEMPLATE/) and the [pull request template](.github/PULL_REQUEST_TEMPLATE.md)

A project in the organization can keep its own copy of any of these files. When it does, the project's file takes precedence.

The public introduction to Necoz lives in the [organization profile](profile/README.md).
